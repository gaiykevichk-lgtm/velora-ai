
## Статус отправки письма подтверждения (2026-10-26)
- `POST /api/auth?action=register` возвращает `emailSent` по фактическому результату отправки, а не по факту наличия настроек SMTP. Если письмо не ушло, интерфейс прямо предлагает повторить отправку.
- `POST /api/auth/verify` (повторная отправка) при сбое транспорта отвечает 503 с текстом «Could not send the confirmation email. Try again later.» вместо общего 500.
