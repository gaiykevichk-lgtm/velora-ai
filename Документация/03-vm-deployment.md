# Развёртывание Velora на существующей VM

Дата: 07.10.2026. Ресурс: cloud-server (9286193).

## Схема
Next.js production под отдельным пользователем velora, systemd с автоперезапуском; nginx на порту 80, Node только на loopback:3000. PostgreSQL 16 на той же VM, доступ только локальный, отдельная роль velora и база velora. База хранится на диске VM, не в sandbox и не в памяти. HTTPS завершается на стандартном домене Promto после app bind.

Исходники: /opt/velora-ai. Секреты: /etc/velora-ai/app.env (root, 600), передаются через systemd EnvironmentFile. Файл не входит в исходники/публичные assets. VELORA_TEST_DB не переносится. DATABASE_URL указывает на локальную PostgreSQL VM. Провайдерные TEXT_*, IMAGE_* и VIDEO_* берутся из локального gitignored .env без вывода значений.

## Эксплуатация
На VM: npm ci, npm test, npm run build; схема через node scripts/setup-db.mjs при установленном DATABASE_URL. Сервисы: velora-ai, nginx, postgresql. Бэкап PostgreSQL необходим для защиты при потере VM; отдельное внешнее хранилище и автоматические резервные копии пока не настроены.

## Ограничения
Самостоятельное пополнение отключено 07.10.2026: POST /api/tokens возвращает 403 TOPUP_DISABLED авторизованным пользователям и 401 гостям, без изменений users/token_transactions. GET сообщает topupEnabled=false, баланс и история доступны как раньше. Публичный коммерческий запуск требует платёжной интеграции и защиты от злоупотреблений. Админка ручных начислений пока отсутствует; отдельный публичный обход блокировки не добавлен. Начальные бесплатные токены при регистрации также требуют production abuse-control. История локальной тестовой базы не переносится.
